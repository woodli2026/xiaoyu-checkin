## clip-path 真机专项验证单（R3 附带，逐机型各填一份）

**背景**：心形（参数方程 44 点）与钻石（7 点明亮式切割）均依赖 `clip-path: polygon()`。部分低端 WebView/旧内核对多点 polygon 支持不佳，可能退化为矩形或整块裁切失效。

| 检查点 | PASS 判据 | iPhone 结果 | Android 结果 |
|---|---|---|---|
| 心形轮廓 | 液体/瓶身呈心形，顶部双弧、底部尖角清晰，**非矩形** | PASS□ FAIL□ | PASS□ FAIL□ |
| 心形棱线/切面感 | 心形内可辨识内壁高光与反光条，有"玻璃"层次 | PASS□ FAIL□ | PASS□ FAIL□ |
| 钻石轮廓 | 7 点切割呈上宽下尖钻石形，可见 facet 棱线分面 | PASS□ FAIL□ | PASS□ FAIL□ |
| 钻石高光 | 顶部/斜面高光条存在，不糊成一片 | PASS□ FAIL□ | PASS□ FAIL□ |
| 瓶内数字位置 | 成长 "x/y" 与心情数字位于瓶内合理位置，不被液面/裁切遮盖 | PASS□ FAIL□ | PASS□ FAIL□ |
| 液面填充精度 | 液体填至 stagePct / mood% 且**不溢出 clip 边界** | PASS□ FAIL□ | PASS□ FAIL□ |
| 气泡 | 气泡在 clip 内部显示，不越界 | PASS□ FAIL□ | PASS□ FAIL□ |

**退化为矩形的判定标准**（任一即判 FAIL）：① 心/钻石轮廓直线化成四边形；② facet 棱线全部消失且整瓶呈实心色块；③ 液体溢出应裁切区域。

**降级方案记录表**（任一 FAIL 必填）：

| 机型 / 系统版本 | 失败检查点 | 现象截图编号 | 采用降级方案 | 降级后是否可接受 |
|---|---|---|---|---|
| | | | （如：该机型回退方形瓶+边框样式 / 降点数简化 polygon / 保持现状记录为已知问题） | |

## Bug 分级约定

| 级别 | 定义 | 示例 |
|---|---|---|
| **P0 阻塞** | 核心循环不可用或造成数据/资产错误 | 投喂后成长值未增加且星星已扣（扣星不加成长） |
| **P1 严重** | 主流程可绕行但关键功能失效 | 展示模式下孩子竟能投喂（权限穿透） |
| **P2 一般** | 功能可用但体验/展示错误 | Android 上心形瓶退化为矩形（已记录降级前） |
| **P3 建议** | 打磨项 | 液面 transition 时长偏长，手感略迟钝 |

Bug 一律记录：复现步骤（环境/前置/步骤/预期/实际）+ 严重度 + 截图，登记后由主理人分派。

## 质量门判定（宠物模块打磨阶段）

**PASS** 须同时满足：
1. P0 Bug = 0，P1 Bug = 0（或已有明确修复排期且不阻塞打磨收尾）；
2. R1 / R2 / R3 三轮用例**全部执行**，无跳过项；
3. clip-path 专项在 iPhone + Android 两台真机上**全 PASS**，或每个 FAIL 项均已在降级表记录方案并确认可接受；
4. 4 个并入的待人工项全部确认 PASS。

**FAIL**：以上任一不满足。判定为建议性门控，最终放行由用户签收。
